# Code of conduct

This project is for people who want to build careful tools. Everyone who takes
part in its issues, pull requests and discussions agrees to the following.

**Be respectful.** Disagree with the idea, the code or the measurement. Do not
attack the person. No harassment, no insults, no remarks about who someone is.

**Be exact.** Say what you ran and what you saw. "It does not work" helps
nobody; a command and its output helps everybody.

**Be honest about limits.** A result that failed is worth reporting. Hiding a
weakness in a change is a reason to close it.

**Respect privacy.** Do not post another person's private information, and do
not paste ledgers, logs or keys that are not yours to share.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, and
block accounts that break these rules. If something happens that you think
breaks them, write to hello@strategic-innovations.ai. Reports are kept private.
